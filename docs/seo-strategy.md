# استراتژی سئو — قطعه فوری (ghetehfori.ir)

> **درباره داده‌ها:** ابزار تحقیق کلمات کلیدی متصل به این پروژه بازار ایران را پشتیبانی نمی‌کند (پاسخ ابزار: «Unsupported location 'Iran'»).
> برای همین **حجم جستجوی هیچ کلمه‌ای در این سند ذکر نشده و همه `UNVERIFIED` هستند.**
> اولویت‌بندی زیر بر اساس نیت خرید و ساختار سایت است، نه آمار.
> سه ماه بعد از راه‌اندازی، با داده واقعی Google Search Console بازبینی شود.

## ۱. آنچه در سایت پیاده‌سازی شده (سئوی تکنیکال)

| مورد | وضعیت |
|---|---|
| URLهای تمیز و سلسله‌مراتبی: `/product-category/body-lights/headlights/`، `/cars/kia/sportage/`، `/cars/kia/sportage/part/headlights/`، `/product/<نام>/` | ✔ |
| **صفحه‌های فرود «دسته + خودرو»** خودکار، با عنوان، H1، توضیحات و canonical اختصاصی (مثلاً «چراغ جلو کیا اسپورتیج») | ✔ |
| نقشه سایت: محصولات، دسته‌ها، خودروها و همه ترکیب‌های «دسته + خودرو» (`/wp-sitemap.xml`) | ✔ |
| **Product schema:** نام، تصویر، SKU، `mpn` (شماره فنی)، برند، دسته، `isAccessoryOrSparePartFor` (خودروهای سازگار)، شماره‌های OEM، وضعیت کالا (نو/استوک)، قیمت و موجودی | ✔ |
| **ستاره‌ها (aggregateRating):** از نظرهای ووکامرس خودکار ساخته می‌شود؛ فقط وقتی محصول نظر دارد | ✔ (نیازمند نظر واقعی) |
| **ارز در schema:** قیمت‌ها به **ریال (IRR)** تبدیل می‌شوند؛ «تومان/IRT» کد ISO نیست و گوگل آن را رد می‌کند | ✔ |
| **AutoPartsStore / Organization schema** با لوگوی PNG، تلفن، نشانی و `sameAs` (اینستاگرام) | ✔ |
| **WebSite + SearchAction** (کادر جستجوی سایت در نتایج گوگل) | ✔ |
| متای توضیحات و Open Graph برای محصول، دسته، خودرو و صفحه اصلی؛ تصویر اشتراک‌گذاری برند | ✔ |
| `noindex, follow` برای نتایج جستجوی داخلی، فیلترها و مرتب‌سازی‌ها (جلوگیری از محتوای تکراری) | ✔ |
| سرعت: LCP بین ۰٫۴ تا ۰٫۷ ثانیه و CLS صفر در تست آزمایشگاهی موبایل (پردازنده ۴ برابر کندتر، سرور محلی) | ✔ (روی هاست واقعی دوباره اندازه‌گیری شود) |
| فونت روی خود سایت، بدون وابستگی به CDN خارجی (پایدار در شرایط محدودیت اینترنت) | ✔ |
| اگر Yoast یا Rank Math نصب شود، عنوان و متای ما کنار می‌رود تا تکراری نشود؛ schema محصول ما حفظ می‌شود | ✔ |

## ۲. خوشه‌های کلمات کلیدی ← صفحه هدف

الگوی اصلی بازار قطعات: **[قطعه] + [خودرو]**، مثل «چراغ جلو تیگو ۷» یا «سنسور اکسیژن توسان». صفحه‌های «دسته + خودرو» دقیقاً برای همین الگو ساخته شده‌اند و ارزشمندترین دارایی سئوی سایت هستند.

| خوشه | نمونه کلمات (حجم: UNVERIFIED) | صفحه هدف |
|---|---|---|
| برند / فوری | خرید فوری لوازم یدکی، قطعه فوری، لوازم یدکی ارسال فوری | صفحه اصلی |
| مبدأ خودرو | لوازم یدکی خودروهای ژاپنی / چینی / کره‌ای / ایرانی، قطعات خودرو چینی | صفحه هر برند خودرو و بخش‌های مبدأ در صفحه اصلی |
| بخش برقی | قطعات برقی خودرو، ECU ماشین، سنسور اکسیژن، دینام، استارت، دسته سیم | `/product-category/electrical/…` |
| بدنه و چراغ | قطعات بدنه خودرو، چراغ جلو، چراغ خطر، مه‌شکن، پروژکتور، سپر، جلوپنجره | `/product-category/body-lights/…` |
| مکانیکی / مصرفی | لنت ترمز، فیلتر روغن، کمک فنر، شمع | `/product-category/mechanical/…` |
| قطعه + خودرو (دُم بلند) | چراغ جلو اسپورتیج، ECU پژو ۲۰۶ تیپ ۵، سپر جلو النترا | `/cars/<برند>/<مدل>/part/<دسته>/` |
| شماره فنی | 92101-D3100، 26300-35505 | صفحه محصول (شماره فنی و OEM در متن و schema) |
| همکاری (B2B) | خرید عمده لوازم یدکی، پخش قطعات خودرو برای تعمیرگاه | صفحه «همکاری» (باید ساخته شود) |

**قاعده:** یک کلمه هدف فقط یک صفحه دارد (بدون هم‌خواری کلمات).

## ۳. محتوا برای هر صفحه

- **دسته‌ها:** ۱۵۰ تا ۳۰۰ کلمه توضیح در ووکامرس › دسته‌ها (کاربرد، نکات انتخاب، تفاوت اصلی، OEM و افترمارکت). این متن توضیحات متای دسته هم می‌شود.
- **محصول:**
  - عنوان با الگوی «[قطعه] [خودرو] [سمت/موقعیت] [اصلی/OEM]».
  - توضیح کوتاه یکتا (کپی متن فروشنده دیگر نه).
  - شماره فنی و OEM در فیلدهای خودشان.
  - حداقل ۳ عکس واقعی با alt توصیفی.
- **خودروها:** برای ۲۰ مدل پرتردد (پژو ۲۰۶، پراید، تیگو ۷، توسان، سراتو، کرولا …) در بخش توضیحات خودرو: تیپ‌ها و سال‌ها و قطعات پرمصرف.
- **بلاگ و راهنما** (ماهانه ۴ تا ۸ مطلب، هدف: جستجوهای اطلاعاتی و لینک داخلی به دسته‌ها):
  - «چطور شماره فنی قطعه را پیدا کنیم»
  - «تشخیص چراغ اصلی از تقلبی»
  - «علائم خرابی سنسور اکسیژن»
  - «ECU نو یا تعمیری؟»
  - «مقایسه لنت OEM و افترمارکت»
  - «راهنمای انتخاب قطعات تیگو ۷»

## ۴. خارج از سایت و کانال‌های ایرانی

- **ترب و ایمالز:** موتورهای مقایسه قیمت ایران، برای قطعات منبع مهم ترافیک خرید هستند. فروشگاه را ثبت کنید. schema محصول (قیمت، موجودی، شماره فنی) خواندن سایت را برایشان ساده می‌کند. **NEEDS VALIDATION:** شرایط و فید مورد نیاز هر کدام را از خودشان بپرسید.
- **Google Business Profile، نشان و بلد:** ثبت فروشگاه یا انبار با همان نام، تلفن و نشانی سایت (یکسان‌بودن NAP).
- **نماد اعتماد (اینماد):** هم برای اعتماد کاربر هم سیگنال کیفیت. کد آن در سفارشی‌سازی › اطلاعات فروشگاه قرار می‌گیرد.
- **اینستاگرام و تلگرام:** لینک اینستاگرام در سفارشی‌سازی (وارد schema می‌شود). محتوای ویدیویی کوتاه «قطعه + خودرو» با لینک به صفحه همان ترکیب.
- **نظرها و ستاره:** بعد از تحویل هر سفارش، پیامک درخواست نظر (قالب پیامک قابل اضافه شدن است). ستاره‌های گوگل فقط از نظرهای واقعی می‌آیند؛ نظر ساختگی ممنوع و خطرناک است.

## ۵. چک‌لیست راه‌اندازی

1. دامنه `ghetehfori.ir` روی هاست ایرانی با SSL. ریدایرکت 301 همه املاهای دیگر و `www` به نسخه اصلی.
2. تنظیمات › پیوندهای یکتا: «نام نوشته». نامک دسته‌ها و خودروها **لاتین** باشد (`headlights`، `kia/sportage`).
3. ووکامرس › نمایش سایت: «زنده» (حالت «به‌زودی» جلوی ایندکس را می‌گیرد).
4. تنظیمات › خواندن: تیک «از موتورهای جستجو بخواهید…» برداشته باشد.
5. ثبت سایت و نقشه `https://ghetehfori.ir/wp-sitemap.xml` در Google Search Console و Bing Webmaster.
6. تست چند محصول در Rich Results Test گوگل.
7. اندازه‌گیری PageSpeed Insights روی هاست واقعی (هدف: LCP زیر ۲٫۵ ثانیه، INP زیر ۲۰۰ میلی‌ثانیه، CLS زیر ۰٫۱).
8. ماه اول: بررسی «صفحات» در Search Console. ماه سوم: بازبینی همین جدول کلمات با داده واقعی نمایش و کلیک.
