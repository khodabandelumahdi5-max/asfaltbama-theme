# آسفالت با ما — بازار B2B قیر و آسفالت + CRM

پلتفرمی شبیه Alibaba.com برای صنعت قیر، آسفالت و راهسازی، ساخته‌شده با Laravel.

## امکانات

**بازار (عمومی)**
- صفحه اصلی با جستجو، دسته‌بندی‌ها، محصولات تازه، تأمین‌کنندگان تأییدشده و استعلام‌های باز
- فهرست محصولات با فیلتر دسته، شهر، «فقط تأییدشده» و مرتب‌سازی قیمت
- صفحه محصول با فرم «تماس با تأمین‌کننده»
- غرفه اختصاصی هر تأمین‌کننده
- **استعلام قیمت (RFQ):** خریدار نیازش را ثبت می‌کند و تأمین‌کنندگان پیشنهاد قیمت می‌دهند

**پنل تأمین‌کننده + CRM**
- داشبورد: آمار، قیف فروش، پیام‌های تازه، پیگیری‌های پیش رو، استعلام‌های جدید
- مدیریت محصولات و پروفایل شرکت
- صندوق پیام‌های خریداران
- **CRM:** قیف فروش کانبانی (سرنخ جدید ← تماس ← مذاکره ← قرارداد / از دست رفته)، پرونده هر مشتری،
  تاریخچه فعالیت‌ها (یادداشت، تماس، جلسه، پیگیری) و یادآور با موعد
- هر پیام محصول یا پیشنهاد قیمت، خریدار را **به‌صورت خودکار** به CRM اضافه می‌کند؛
  وقتی خریدار پیشنهاد را بپذیرد، مرحله مشتری به «قرارداد بسته شد» می‌رود

**پنل خریدار:** استعلام‌های من، مقایسه پیشنهادها (مرتب‌شده بر اساس قیمت) و پذیرش بهترین پیشنهاد

**مدیر سایت:** تأیید / لغو تأیید تأمین‌کنندگان

ظاهر کاملاً فارسی و راست‌چین، فونت وزیرمتن، تاریخ شمسی و اعداد فارسی، واکنش‌گرا برای موبایل.

## اجرا

```bash
cd platform
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

سپس `http://localhost:8000` را باز کنید. حساب‌های نمونه (رمز همه: `password`):

| نقش | ایمیل |
|---|---|
| مدیر | `admin@asfaltbama.ir` |
| تأمین‌کننده (با CRM نمونه) | `supplier@asfaltbama.ir` |
| خریدار | `buyer@asfaltbama.ir` |

برای محیط واقعی، در `.env` پایگاه داده را روی MySQL تنظیم کنید (`DB_CONNECTION=mysql`)، `APP_DEBUG=false` بگذارید و رمز حساب‌های نمونه را عوض کنید (یا seed نکنید).


## ساختار

- `app/Models` — `Company`, `Product`, `Category`, `Rfq`, `Quote`, `Inquiry`, `CrmContact`, `CrmActivity`
- `app/Http/Controllers` — صفحات عمومی؛ `Panel/` پنل کاربران و CRM؛ `Admin/` مدیریت
- `app/Support/helpers.php` — تاریخ شمسی (`jdate`)، اعداد فارسی (`fa_number`)، قیمت (`toman`)
- `resources/views` — قالب‌های Blade؛ `public/css/app.css` — استایل برند
