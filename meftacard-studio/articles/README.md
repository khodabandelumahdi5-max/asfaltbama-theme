## Method and limits

- Keyword choice is based on live Google results, autocomplete patterns and competitor pages (Nov 2026). Search **volumes were not available** (the keyword-data tool had no credits). Validate volumes in Search Console after 4–6 weeks and re-prioritise.
- Price figures quoted in the articles are from public sources, linked inline, and labelled as estimates.
- No invented statistics, client names or testimonials.

## Before publishing

1. Have a native Arabic speaker edit the Arabic articles once (tone, Iraqi/Gulf examples).
2. Publish the Arabic posts with `lang="ar"` (the current WordPress install outputs `lang="fa-IR"` on Arabic posts — fix first).
3. Add hreflang for the two pairs above.
4. Add a featured image and alt text per article.
5. Publish 2–3 per week rather than all at once, and request indexing in Search Console.
