# قطعه فوری — فروشگاه تخصصی قطعات خودروهای چینی، کره‌ای و ژاپنی

نسخه اول سایت و پنل کاری، بر اساس توصیه‌های مشاوره (آرش الطافیان). Laravel، فارسی و راست‌چین.

## مسیر خرید مشتری
انتخاب خودرو → جستجوی نام یا شماره فنی → فقط قطعات سازگارِ تأییدشده → بررسی مشخصات و موجودی → افزودن به سبد یا «درخواست تطبیق» → ثبت سفارش (بدون پرداخت) → تأیید قیمت/موجودی/تطبیق توسط کارکنان → پرداخت → پیگیری سفارش

## قبل از راه‌اندازی، این موارد را خودتان تعیین کنید
داده‌های فعلی نمونه‌اند و بعضی متن‌ها تعهد تجاری هستند:
- **`config/shop.php`**: تلفن، ساعت پاسخ‌گویی، زمان پاسخ، تعریف «فوری»، هزینه ارسال هر شهر، وعده‌های صفحه اصلی. فقط وعده‌ای را نگه دارید که در همه سفارش‌ها اجرایش ممکن است.
- **`resources/views/pages/shipping.blade.php`**: متن شرایط مرجوعی پیش‌نویس است. با شرایط واقعی بنکدارها، مخصوصاً برای قطعات برقی، تطبیق بدهید.
- کالاها، خودروها و تأمین‌کنندگان نمونه را حذف کنید و ۳۰ تا ۵۰ قلم واقعی وارد کنید. شماره‌های فنی با پیشوند `DEMO-` واقعی نیستند.
- **پرداخت آنلاین** وصل نشده است. سفارش پس از تأیید کارکنان، با لینک پرداخت (خارج از سایت) تسویه می‌شود.

## اجرا
```bash
cd ghatefori
composer install && cp .env.example .env && php artisan key:generate
touch database/database.sqlite && php artisan migrate --seed && php artisan storage:link
php artisan serve
```
- فروشگاه: `http://localhost:8000`
- پنل کارکنان: `http://localhost:8000/admin`. رمز همه حساب‌های نمونه `password` است.
  - `manager@ghatefori.ir` مدیر (قیمت خرید، سود، گزارش هفتگی)
  - `sales@ghatefori.ir` فروش
  - `tech@ghatefori.ir` فنی
  - `ship@ghatefori.ir` ارسال

```bash
php artisan test
```
