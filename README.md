# asfaltbama-theme

فروشگاه آنلاین قطعات خودرو روی وردپرس + ووکامرس.

- `wordpress/plugins/yadak-core` — افزونه اصلی: سازگاری با خودرو، شماره فنی/OEM، جستجوی فارسی، گاراژ، قیمت همکار، خرید اعتباری و حساب مشتری، تاریخچه قیمت، Excel/CSV
- `wordpress/themes/yadak-child` — قالب فرزند Hello Elementor (راست‌به‌چپ، موبایل‌محور)
- `dist/` — فایل‌های zip آماده نصب
- `asfaltbama.zip` — قالب مادر Hello Elementor
- `docs/site-setup.md` — راهنمای نصب و کار با سایت
- `docs/master-prompt-iran-auto-parts.md` — پرامپت مادر استراتژی برند و پلتفرم
