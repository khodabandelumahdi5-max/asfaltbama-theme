# سایت رسمی BAVAR GROUP

سایت گروه توسعه کسب‌وکار باور — **Founder Arash Altafian**
مشکی و سفید، مینیمال، لوکس و موبایل‌محور؛ روی وردپرس + ووکامرس.

| پوشه | چیست |
|---|---|
| `bavar-theme/` | پوسته‌ی سایت (فرزند Hello Elementor): صفحه‌ی اصلی، صفحه‌ی دوره، صفحه‌ی پک، کتابخانه، استایل همه‌ی صفحات |
| `bavar-core/` | افزونه‌ی اصلی: فرم ورود، فرم سه‌سؤالی، لیدها، کتاب‌ها، پرداخت کارت‌به‌کارت با ارسال فیش، اسپات‌پلیر، «کتابخانه من» |
| `dist/` | فایل‌های zip آماده‌ی نصب (`bavar-theme.zip` و `bavar-core.zip`) |
| `asfaltbama.zip` | پوسته‌ی والد Hello Elementor (باید نصب باشد) |

## نصب

1. وردپرس فارسی نصب کنید و از **افزونه‌ها ← افزودن** افزونه‌ی **WooCommerce** را نصب و فعال کنید.
2. **نمایش ← پوسته‌ها ← افزودن ← بارگذاری**: اول `asfaltbama.zip` (Hello Elementor) و بعد `dist/bavar-theme.zip` را نصب و **BAVAR GROUP** را فعال کنید.
3. **افزونه‌ها ← افزودن ← بارگذاری**: `dist/bavar-core.zip` را نصب و فعال کنید.
   با فعال‌سازی، این کارها خودکار انجام می‌شود:
   - ساخت برگه‌های **BAVAR LIBRARY**، **آشیانه سیمرغ‌ها** و **مشاوره**
   - تنظیم ووکامرس برای فروش دیجیتال: الزام ساخت حساب هنگام خرید، دانلود فقط برای کاربر واردشده، فعال‌شدن دسترسی بعد از پرداخت، واحد پول تومان
   - تبدیل صفحه‌ی پرداخت به حالت کلاسیک (برای فیلدهای نام، موبایل و شغل)
4. **تنظیمات ← پیوندهای یکتا** را روی «نام نوشته» بگذارید و ذخیره کنید.
5. **ووکامرس ← تنظیمات ← Site visibility**: وقتی آماده‌ی انتشار شدید، سایت را از حالت **Coming soon** روی **Live** بگذارید. تا وقتی این کار انجام نشود، بازدیدکننده‌ها فروشگاه را نمی‌بینند.

## مسیر کاربر

1. **ورود به سایت** ← فرم «نام و نام خانوادگی، شماره تماس، شغل». اطلاعات ثبت می‌شود و تا یک سال دوباره پرسیده نمی‌شود.
2. **انتخاب یکی از ۴ مسیر** ← سه سؤال همان مسیر (نام، موبایل و شغل خودکار پر شده‌اند) ← رفتن به صفحه‌ی مقصد.
3. **خرید** ← دکمه‌ی خرید مستقیم به صفحه‌ی پرداخت می‌رود؛ نام، موبایل و شغل از قبل پر شده‌اند. خریدار یک رمز انتخاب می‌کند و **شماره موبایلش نام کاربری اوست**.
4. **پرداخت**:
   - **کارت‌به‌کارت** (داخل افزونه): شماره کارت نمایش داده می‌شود، خریدار فیش را همان‌جا یا با **لینک اختصاصی ارسال فیش** (در ایمیل و در «کتابخانه من») بارگذاری می‌کند. مدیر در صفحه‌ی سفارش فیش را می‌بیند و وضعیت را **«تکمیل‌شده»** می‌کند؛ دسترسی خریدار خودکار فعال می‌شود.
   - **درگاه آنلاین**: افزونه‌ی درگاه ووکامرس (مثلاً زرین‌پال یا هر درگاهی که دارید) را نصب کنید. بعد از پرداخت موفق، دسترسی **بدون دخالت مدیر** فعال می‌شود.
5. **MY BAVAR ← کتابخانه من** ← هر دوره و پک خریداری‌شده با دکمه‌ی **دانلود PDF** یا کد لایسنس اسپات‌پلیر.

## کار روزانه‌ی مدیر

### افزودن پک جدید (برای ۱۰۰+ پک)
1. **محصولات ← افزودن**: نام، قیمت، تصویر شاخص، توضیح کوتاه.
2. در «اطلاعات محصول» تیک **مجازی** و **دانلودی** را بزنید و فایل‌های PDF پک را در «فایل‌های قابل دانلود» اضافه کنید. محدودیت دانلود را خالی بگذارید (نامحدود).
3. در باکس **BAVAR — نوع محصول و محتوا**: نوع را «پک کتابخانه‌ی باور» بگذارید و موضوع و «محتوای قابل دریافت» را بنویسید.
4. برای فیلتر موضوع در کتابخانه، پک را در یک **دسته‌بندی محصول** (مثلاً «فروش») قرار دهید.
5. ذخیره کنید و با دکمه‌ی **«+ افزودن کتاب به این پک»** کتاب‌ها را یکی‌یکی اضافه کنید.

### افزودن کتاب
**BAVAR ← کتاب‌ها ← افزودن کتاب**: عنوان، توضیح، **تصویر جلد**، نویسنده، موضوع، «چرا این کتاب انتخاب شده؟»، خلاصه / محتوای BAVAR، چک‌لیست (هر مورد در یک خط)، تمرین، و **پک** مربوطه.
ترتیب نمایش با «ترتیب» (Order) تعیین می‌شود. در فهرست کتاب‌ها می‌توانید بر اساس پک فیلتر کنید.
هر کتاب در صفحه‌ی پک بخش جدا، شماره (BOOK 01 / 40) و خط جداکننده‌ی خودش را دارد و فهرست کتاب‌ها بالای صفحه لینک مستقیم به هر کتاب است.

### دوره‌ی «کتاب مقدس گروه باور»
یک محصول بسازید و نوع را «دوره» بگذارید. زیرعنوان، قالب‌ها (Audio / Video / Text / Exercises / Practical Materials) و ۸ بخش صفحه (دوره چیست؟، برای چه کسانی است؟، …، پشتیبانی) را پر کنید. قیمت از خود محصول تغییر می‌کند.
**اسپات‌پلیر (اختیاری):** کلید API را در **BAVAR ← تنظیمات** و شناسه‌ی دوره را در صفحه‌ی محصول وارد کنید؛ بعد از پرداخت، لایسنس خودکار ساخته می‌شود و در «کتابخانه من» نمایش داده می‌شود. (نشانی و فرمت API اسپات‌پلیر را پیش از استفاده‌ی واقعی با مستندات پنل خود یکبار تطبیق دهید؛ اگر ساخت لایسنس ناموفق باشد، دلیلش در یادداشت‌های سفارش ثبت می‌شود.)

### لیدها و درخواست‌ها
**BAVAR ← لیدها و درخواست‌ها**: همه‌ی ورودی‌ها (فرم ورود، فرم سه‌سؤالی، سفارش‌ها) با تاریخ، نام، موبایل، شغل، مسیر / محصول، پاسخ سه سؤال و **وضعیت خرید** (لید / در انتظار پرداخت / خریدار) و لینک سفارش. فیلتر، جستجو و **خروجی Excel (CSV)** دارد.

### تنظیمات
- **BAVAR ← تنظیمات**: متن فرم ورود و حالت آن (اجباری / قابل بستن / خاموش)، عنوان‌ها و متن دکمه‌ها و **سه سؤال هر مسیر**، برگه‌های مقصد، اسپات‌پلیر.
- **نمایش ← سفارشی‌سازی ← BAVAR GROUP**: تصویر اصلی، متن معرفی، BAVAR PHILOSOPHY، تصاویر و معرفی مؤسس، تلفن، ایمیل، اینستاگرام، تلگرام، لینک قوانین و حریم خصوصی.
- **ووکامرس ← تنظیمات ← پرداخت‌ها ← کارت به کارت + ارسال فیش**: شماره کارت، نام صاحب حساب، بانک، شبا.
- کوپن تخفیف، سفارش‌ها، کاربران و فعال/غیرفعال کردن دسترسی دانلود (در صفحه‌ی هر سفارش) از امکانات خود ووکامرس است.

## امنیت فایل‌ها
- PDFها در `wp-content/uploads/woocommerce_uploads` نگهداری می‌شوند و فقط از طریق لینک امضاشده‌ی ووکامرس، برای خریدار واردشده، دانلود می‌شوند (آزمایش شد: تغییر شناسه‌ی فایل در لینک، دانلود پک خریداری‌نشده را رد می‌کند).
- فیش‌ها در `wp-content/uploads/bavar-receipts` با نام تصادفی ذخیره می‌شوند و فقط مدیر آن‌ها را می‌بیند.
- روی **Apache** فایل‌های `.htaccess` دسترسی مستقیم به این دو پوشه را می‌بندند. روی **Nginx** این را به تنظیمات سرور اضافه کنید:
  ```nginx
  location ~* ^/wp-content/uploads/(woocommerce_uploads|bavar-receipts)/ { deny all; }
  ```

## آزمایش‌شده
روی وردپرس ۷٫۱ + ووکامرس، دسکتاپ و موبایل: فرم ورود (با اعداد فارسی)، خطای شماره‌ی نامعتبر، فرم سه‌سؤالی و انتقال به دوره / مشاوره، کتابخانه، صفحه‌ی پک، پرداخت با پیش‌پرشدن فیلدها، سفارش کارت‌به‌کارت، ارسال فیش، تأیید مدیر و فعال‌شدن دانلود، ورود با شماره موبایل، دانلود PDF، جلوگیری از دانلود پک خریداری‌نشده، ثبت لیدها و خروجی CSV، افزودن کتاب و ویرایش پک از پیشخوان.

## قدم‌های بعدی پیشنهادی
- **پیامک**: یک افزونه‌ی پیامک ووکامرس (کاوه‌نگار، ملی‌پیامک و …) نصب کنید تا لینک ارسال فیش و تأیید خرید با SMS هم ارسال شود.
- **تاریخ شمسی** در پیشخوان: افزونه‌ی «پارسی دیت» یا مشابه.
- **ترجمه‌ی فارسی ووکامرس** از **پیشخوان ← به‌روزرسانی‌ها ← به‌روزرسانی ترجمه‌ها** تا صفحه‌ی پرداخت و حساب کاربری کاملاً فارسی شود.
