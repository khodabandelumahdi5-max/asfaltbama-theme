# قطعه فوری / GetFori — ghetehfori.ir

فروشگاه آنلاین قطعات خودرو روی وردپرس + ووکامرس.

- `wordpress/plugins/yadak-core` — افزونه اصلی: سازگاری با خودرو (ژاپنی/چینی/کره‌ای/ایرانی)، فیلتر پیشرفته (شماره فنی، مدل، سال ساخت)، جستجوی فارسی، ویرایش سریع و گروهی قیمت و موجودی، قیمت همکار، اعتبار و حساب مشتری، پیش‌فاکتور، CRM و قیف فروش، چند انبار، پیامک، زرین‌پال و کارت‌به‌کارت، فاکتور و خروجی مودیان، تاریخ شمسی، صفحه‌های سئو و اسکیما (Product/AutoPartsStore)، داشبورد، نمای سه‌بعدی/AR محصول
- `wordpress/themes/yadak-child` — قالب فرزند Hello Elementor (راست‌به‌چپ، موبایل‌محور، خودروی سه‌بعدی تعاملی)
- `dist/` — فایل‌های zip آماده نصب
- `asfaltbama.zip` — قالب مادر Hello Elementor
- `docs/site-setup.md` — راهنمای نصب و کار با سایت
- `docs/brand.md` — هویت برند (نام، لوگو، رنگ، لحن، دامنه)
- `docs/seo-strategy.md` — استراتژی سئو و چک‌لیست راه‌اندازی
- `docs/master-prompt-iran-auto-parts.md` — پرامپت مادر استراتژی برند و پلتفرم
