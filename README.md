# asfaltbama-theme

فروشگاه آنلاین قطعات خودرو روی وردپرس + ووکامرس.

- `wordpress/plugins/yadak-core` — افزونه اصلی: سازگاری با خودرو (چینی/ژاپنی/کره‌ای)، جستجوی فارسی، قیمت همکار، اعتبار و حساب مشتری، پیش‌فاکتور، CRM و قیف فروش، چند انبار، پیامک، زرین‌پال و کارت‌به‌کارت، فاکتور و خروجی مودیان، تاریخ شمسی، صفحه‌های سئو، داشبورد، نمای سه‌بعدی/AR محصول
- `wordpress/themes/yadak-child` — قالب فرزند Hello Elementor (راست‌به‌چپ، موبایل‌محور، خودروی سه‌بعدی تعاملی)
- `dist/` — فایل‌های zip آماده نصب
- `asfaltbama.zip` — قالب مادر Hello Elementor
- `docs/site-setup.md` — راهنمای نصب و کار با سایت
- `docs/master-prompt-iran-auto-parts.md` — پرامپت مادر استراتژی برند و پلتفرم
