# اپ موبایل «قطعه فوری» (Flutter)

اپ اندروید و iOS فروشگاه، با داده زنده از همان سایت ووکامرس. نسخه اول: صفحه اصلی بومی، و صفحه‌های محصول، سبد، پرداخت، حساب و گاراژ در مرورگر داخل اپ.

## صفحه اصلی

- **نوار ارسال:** «تا ساعت ۱۴ سفارش دهید، امروز ارسال می‌شود». همان منطق سایت است: بعد از ساعت پایان «فردا» و پنجشنبه عصر و جمعه «شنبه».
- **جستجو** با نام قطعه، شماره فنی یا OEM. نتیجه در صفحه جستجوی سایت باز می‌شود.
- **استعلام با عکس یا شماره شاسی (VIN):** دکمه، واتس‌اپ کارشناس را با پیام آماده باز می‌کند و مشتری عکس کارت خودرو یا قطعه را همان‌جا می‌فرستد.
- **کشور سازنده خودرو:** چین، ژاپن، کره، ایران، آلمان و اروپا. هر کارت فیلتر فروشگاه را با همان مبدأ باز می‌کند.
- **پرفروش‌ترین قطعات** از Store API ووکامرس:
  - قیمت با ارقام فارسی
  - شماره فنی و خودروهای سازگار (از افزونه Yadak Core)
  - موجودی **واقعی** انبار: «موجود»، «ناموجود» یا «فقط N عدد در انبار» وقتی موجودی کم است
- **پشتیبانی:** واتس‌اپ و تماس تلفنی.

## ساخت و اجرا

پیش‌نیاز: [Flutter](https://docs.flutter.dev/get-started/install) نسخه ۳.۳۵ یا جدیدتر.

```bash
cd app
flutter pub get
flutter run --dart-define=SITE_URL=https://ghetehfori.ir \
            --dart-define=WHATSAPP=09121234567 \
            --dart-define=PHONE=02112345678
```

برای ساخت فایل نصب اندروید:

```bash
flutter build apk --release --dart-define=SITE_URL=https://ghetehfori.ir \
  --dart-define=WHATSAPP=09121234567 --dart-define=PHONE=02112345678
# خروجی: build/app/outputs/flutter-apk/app-release.apk
```

| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| `SITE_URL` | `https://ghetehfori.ir` | نشانی سایت، بدون `/` آخر |
| `WHATSAPP` | خالی | شماره واتس‌اپ کارشناس؛ خالی = دکمه واتس‌اپ نمایش داده نمی‌شود |
| `PHONE` | خالی | تلفن فروشگاه |
| `SHIP_CUTOFF` | `14` | ساعت پایان ارسال همان‌روز؛ `0` = پیام ارسال نمایش داده نشود |

## نیازهای سمت سایت

- ووکامرس نسخه ۸٫۵ به بالا. Store API (`/wp-json/wc/store/v1/products`) عمومی است و کلید نمی‌خواهد.
- افزونه Yadak Core به‌روز باشد تا شماره فنی و خودروها در پاسخ API باشند (`extensions.yadak`).
- سایت باید HTTPS معتبر داشته باشد؛ اندروید درخواست HTTP ساده را در نسخه release مسدود می‌کند.

## انتشار

- **شناسه بسته:** `ir.ghetehfori.ghateh_foori`. قبل از اولین انتشار در بازار یا مایکت، کلید امضای release بسازید (`android/key.properties`) و آن را جای امنی **خارج از مخزن** نگه دارید.
- **آیکن‌ها** از نشان برند ساخته شده‌اند (`android/.../mipmap-*`، `ios/.../AppIcon.appiconset`، `web/icons`).
- **iOS:** نیاز به مک، Xcode و حساب اپل دارد؛ انتشار iOS برای کاربران ایرانی محدودیت‌های خودش را دارد.
